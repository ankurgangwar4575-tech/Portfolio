# 🌐 Ankur Gangwar | Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, and Vite. This project showcases education, skills, projects, coding profiles, and contact information in a clean and professional layout.

## ✨ Features

- Responsive single-page design for desktop and mobile
- Smooth scrolling and active navigation highlighting
- Sections for About, Skills, Education, Projects, Coding Profiles, and Contact
- Downloadable resume button
- Project cards with optional live demo and GitHub links
- Contact form that opens the user's email app with a pre-filled message
- Elegant dark-themed UI with a polished user experience

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- ESLint

## 🚀 Getting Started

### Prerequisites

- Node.js 20 or later
- npm

### Installation

```powershell
git clone <your-repository-url>
cd Portfolio/MyPortfolio
npm install
npm run dev
```

The app will usually open at:

```text
http://localhost:5173
```

## 🎨 Customization

All portfolio content is stored in the data file inside the project. You can update your:

- Name and intro
- Skills and education
- Projects and links
- Coding profiles
- Resume file

## 📦 Available Scripts

```powershell
npm run dev     # Start the development server
npm run build   # Create a production build
npm run preview # Preview the production build locally
npm run lint    # Run ESLint checks
```

## 🌍 Deployment

Build the project for production:

```powershell
npm run build
```

Then deploy the generated `dist` folder to any static hosting service such as Vercel, Netlify, or GitHub Pages.
